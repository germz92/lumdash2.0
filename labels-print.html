Layout

If the code is off-centre on the sticker, nudge it. Positive moves right / down; negative moves left / up. On a Brother QL, try about −0.5 mm if there is extra space on the left.

Sheet layouts differ between brands. Use the measurements from your label pack or its template, then save time later: these settings are remembered on this computer.
